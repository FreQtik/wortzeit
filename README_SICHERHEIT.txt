SICHERHEIT / DATENSCHUTZ – DEMO-DEPLOYMENT
=========================================

1. GitHub Pages ist öffentlich erreichbar. Deshalb enthält dieser Web-Build keine echten Patientenprofile oder privaten Therapiepakete.
2. Das Passwort "qqq" ist nur ein Soft-Gate gegen versehentliches Öffnen des Behandlerbereichs. Bei einer statischen Website ist ein im Browser geprüftes Passwort keine echte Zugriffskontrolle.
3. Persönliche Behandlerdaten, eigene Listen, Patienten-Zuordnungen und Einstellungen werden durch WortZeit lokal im Browser des jeweiligen Geräts gespeichert.
4. Ein anderer Besucher der öffentlichen Website erhält NICHT automatisch die lokalen Daten deines Vaters.
5. Keine .speechpack-Dateien mit Patientendaten, Audioaufnahmen oder identifizierenden Informationen ins öffentliche Repository laden.
6. Für einen späteren produktiven Behandler-Onlinezugang mit echter Zugriffskontrolle wäre ein authentifizierter Dienst notwendig. Für den morgigen Test ist die aktuelle Trennung bewusst serverlos und risikoarm gehalten.
